Sunset Cover Studio is an offline web app that turns your own photos into bold GTA-style poster cover art. Drop in one photo or several, pick a multi-panel layout (three strips, a 2×2 grid, or a hero shot with a bottom strip), drag each photo to crop and position it, tune its zoom, choose a sunset or neon-night colour grade, and type a big bold title and subtitle. The live preview is exactly what you export: a PNG in 1080×1080, 1080×1350, or 1920×1080, ready to post. Everything runs locally in your browser — photos are read on your machine and never uploaded — and all artwork is original, drawn in code with the open-licensed Anton typeface.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Add photos, arrange the panels, and press Export PNG.
